# Authentication API



This authentication API that uses python version 3.14.8 and is designed to demonstrate secure user registration and login. It validates user input, and applies secure password hash storage and returns.

&#x20;

### Features



User registration and login

Password hashing and verification

Input validation

REST API endpoints

Appropriate HTTP responses



### Running the API



Create a virtual environment

python -m venv .venv



Activate it 

.venv\\Scripts\\Activate.ps1



Install dependencies

python -m pip install -r requirements.txt



Generate a JWT secret

python -c "import secrets; print(secrets.token\_hex(32))"



Set the generated value

$env:JWT\_SECRET="paste-your-generated-value-here"



Run the API

uvicorn main:app --reload



Open the API docs

http://127.0.0.1:8000/docs



#### Testing

Tests use a separate temporary SQLite database rather than auth.db. This ensures test data is kept separate from the actual database to prevent tests from changing it or deleting real data. 



To run Pytest

pytest -m pytest 



This should result in 6 tests passed
